# 창업과 실용법률 중간고사 통합 웹모의고사

`index.html` 파일을 GitHub 저장소 최상위(root)에 업로드합니다. `Settings → Pages → Deploy from a branch → main → /(root) → Save`를 설정하세요. 몇 분 후 표시된 주소에서 모바일로 접속할 수 있습니다.

- 기출 집중(3회차): 기출·족보 복원 문장 보존을 우선하며 일부 선택지는 새로 구성했습니다. 각 문제에 구분 표시.
- 핵심 예상(4회차): 1~7주차 내용에 기반한 새 문항.
- 기존 2회차: 이전 HTML의 문항 유지.
- 세트당 OX 40 / 객관식 50 / 50분 / 190점.
- 데이터는 index.html에 내장되어 있으므로 따로 서버 설정이 필요 없습니다. questions.json은 수정·검토 편의를 위한 백업 파일입니다.

⚠️ 기출 파일은 공식 원본 시험지가 아니라 수강생 작성 복원·족보입니다. `원문 복원`은 제공된 복원 문장을 기준으로 하며 공식 문항 동일성을 보장하지 않습니다. 일부 원문에 선택지가 없어 새로 구성한 선지가 포함됩니다.
